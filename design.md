# DESIGN.md
# NikkoDev Design System

---

# Filosofía

El portafolio NO es una galería de proyectos.

El portafolio es una demostración de capacidad.

Su objetivo es que una persona piense:

"Este ingeniero puede construir prácticamente cualquier sistema moderno."

---

# Posicionamiento visual

No parecer:

- Un portfolio estudiantil.
- Un portfolio de diseñador.
- Un dashboard SaaS genérico.
- Un portfolio cyberpunk.
- Una landing de agencia.

Sí parecer:

- Centro de control de ingeniería.
- Laboratorio de innovación.
- Sistema operativo para crear productos.
- Terminal moderna.
- Plataforma técnica premium.

---

# Concepto Principal

## NikkoDev OS

El portafolio debe sentirse como:

"El centro de control de un ingeniero especializado en velocidad, SEO, IA y sistemas modernos."

Referencia conceptual:

- Bash
- Linux
- Apple
- Anthropic
- Huawei
- Centros de monitoreo
- Sistemas operativos

# Animaciones

Regla:

90% elegancia
10% espectáculo

---

# Permitido

- Fade
- Reveal
- Hover
- Expand
- Scroll suave
- Counters

---

# Prohibido

- Parallax agresivo
- Giros innecesarios
- Scroll cinematográfico
- Efectos que reduzcan FPS

---

# Rendimiento

La web debe sentirse absurda de rápida.

Nunca sacrificar:

- SEO
- Accesibilidad
- Rendimiento

por estética.

---

# Lo que odiamos

- Portfolios lentos
- Portfolios excesivamente cinematográficos
- Skill bars
- Porcentajes falsos
- Mucho texto
- Animaciones que cansan

---

# Regla Final

La sensación final debe ser:

"Una terminal bash evolucionada en una interfaz premium donde un ingeniero muestra plataformas reales, IA aplicada y sistemas modernos."

No vender diseño.

Vender capacidad.
